# 测测你的 XP｜问卷项目

## 文件
- `index.html`：页面结构
- `style.css`：页面样式与移动端适配
- `data.js`：25 道题目、选项和 11 种结果文案
- `app.js`：答题流程、计分判定、结果展示与分享

## 本地运行
解压后直接双击 `index.html` 即可。也可以使用 VS Code 的 Live Server。

## GitHub Pages 部署
1. 将四个文件上传到 GitHub 仓库根目录。
2. 打开仓库 Settings → Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/(root)`，保存。
5. 等待部署完成后访问 GitHub Pages 显示的网址。

直接进入第一题的链接：在网站网址后添加 `?start=1`。

## 计分规则
- 统计 25 道题中 A/B/C/D 各自被选择的次数。
- 前三名分数跨度不超过 2：日常沉浸·多面型。
- 否则最高分比第二高至少多 3：对应 A/B/C/D 纯型。
- 其余情况：按最高两项组合映射为六种双高混合型。

本问卷仅供娱乐，不是经过验证的心理测量工具。答案仅保存在当前页面运行期间，刷新页面会重新开始；项目没有后端或用户数据统计。
